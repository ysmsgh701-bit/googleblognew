## 4. 사실확인 — 과단정 완화 4건

웹 검증 자료: 가수금·가지급금 가계정 정의 및 결산 시 확정계정 대체 원칙(공인회계사 실무 칼럼·회계법인 실무 자료 복수), suspense account / clearing account 정의와 기말 잔액 처리 관행(Wikipedia, 대학 회계 부서 best practice 문서, 회계 실무 블로그 복수).

### 4-1. 검증 결과 정확한 서술 (수정 없음)

- 가수금 = 현금 수입은 있으나 거래 내용이 확정되지 않아 임시 처리하는 계정(부채성 가계정), 가지급금 = 현금 지출은 있으나 계정과목·금액이 확정되지 않아 임시 처리하는 계정(자산성 가계정) — **정확**.
- 임시 계정은 결산 시 원인을 확인해 확정계정으로 대체해야 하며, 잔액이 남아 있으면 정리되지 않은 거래가 있다는 신호 — **정확**(#11:91과도 정합).
- 기말 임시 계정 잔액에 대해 감사인이 설명을 요구한다는 실무 관행 — **정확**.
- 발생 4계정(미지급비용·미수수익·선급비용·선수수익)은 시차를 담아두는 정상 잔액 계정이고, 임시 계정은 반대 성격 — **정확**(#20:148~157).
- 미결계정(clearing) 잔액이 자동 매칭 규칙과 실제 거래 모양의 불일치에서 생긴다는 서술 — **정확**.
- 예방/적발 통제 분류에서 임시 계정 잔액 훑기가 적발 통제·사람 담당으로 분류된다는 인용 — #17:122 원문과 일치.

### 4-2. 완화·정밀화한 4건

1. **[과단정 완화 + 사실 정밀화]** H2 "임시 계정은 이름이 달라도 **성격이 하나입니다**" → "**이름은 달라도, 결산에서 보는 방식은 같습니다**", 본문 첫 문장도 재작성. 공개 자료상 clearing account(정상 거래가 잠시 거쳐 가는 통로)와 suspense account(원인 확인이 필요한 항목의 표시)는 **목적이 다른 계정**이라 "성격이 하나"는 부정확했습니다. 수정본은 쓰임새 차이를 먼저 인정한 뒤 "결산 시점에 시산표를 놓고 보면 한 묶음이 된다"로 범위를 좁혔습니다.
2. **[과단정 완화]** "**시스템은 아무 경보도 울리지 않습니다**" → "**웬만한 검산 규칙에는 걸리지 않습니다**". ERP·검증 설정에 따라 임시 계정 aging 경보를 두는 회사가 있어 전면 단정이 부정확했습니다.
3. **[정밀화]** "장부 안에서 답이 나오는 항목이 하나도 없습니다" → "**장부 안에서만** 답이 나오는 항목은 하나도 없습니다". 원문은 장부에서 아무 단서도 안 나온다는 뜻으로 읽혀 과장이었습니다.
4. **[회계 요건 단정 회피]** 자동화 섹션 불릿 1의 "'가수금 잔액은 마감 시점에 0이어야 한다'" 앞에 "**회사가 정한 기준을 그대로 옮기면**"을 붙였습니다. 마감 시점 0 요건은 회사 규정·기준마다 달라 블로그가 요건으로 단정할 자리가 아닙니다.

(그 외 결과 단언 완화 1건 — 마무리의 "이 두 가지**만 지켜도** … '매달 조금씩 줄어드는 목록'**이 됩니다**" → "이 두 가지를 지키면 … **쪽에 가까워집니다**". §7 수정 내역에 포함.)
