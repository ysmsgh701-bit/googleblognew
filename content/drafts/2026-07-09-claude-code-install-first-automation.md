# 클로드 코드 사용법 — 재무 실무자의 설치부터 첫 자동화까지

"클로드 코드"라는 이름을 처음 들었을 때, 저는 이게 개발자 전용 도구인 줄 알았습니다.
"코드"라는 단어가 붙어 있으니까요. 검은 화면(터미널)에 뭔가를 타이핑하는 것 자체가
낯설고, 잘못 누르면 컴퓨터가 고장 날 것 같은 막연한 두려움도 있었습니다.

저는 20년 가까이 숫자만 만져온 재무 실무자입니다. 프로그래밍 수업 한 번 들어본 적
없습니다. 그런 제가 지금은 클로드 코드로 해외법인 월마감·연결패키지 자동화 작업을
진행하고 있습니다. 이 글은 그 첫걸음, 즉 설치부터 "이게 진짜 되네" 싶었던 첫 자동화
경험까지의 기록입니다. 저와 같은 처지의 사무직 독자를 위한 글입니다.

## 설치는 생각보다 어렵지 않았습니다

가장 겁냈던 부분이 오히려 제일 쉬웠습니다. 터미널(윈도우에서는 명령 프롬프트나
PowerShell)을 열고 아래 명령어 한 줄을 치면 끝입니다.

```
npm install -g @anthropic-ai/claude-code@latest
```

다만 이 명령어가 작동하려면 컴퓨터에 Node.js(버전 18 이상)가 먼저 깔려 있어야
합니다. 저도 처음엔 이 단어부터 몰라서 검색부터 해야 했습니다. 설치가 끝났는지는
`claude --version` 명령으로 확인하고, 이후 `claude` 명령으로 실행한 뒤 계정
인증(로그인)을 한 번 거치면 바로 쓸 수 있습니다. 설치 자체는 30초 정도면 끝나는
작업이었습니다. "코딩을 몰라서 설치도 못 할 것"이라는 제 걱정은 기우였습니다.

## 첫 삽질: 파이썬 버전이 꼬였습니다

설치보다 오히려 여기서 시간을 더 썼습니다. 제 컴퓨터에는 이미 다른 프로그램이 깔아둔
파이썬이 있었는데, 이게 제가 새로 쓰려는 버전과 충돌했습니다. 클로드 코드가 짜준
코드를 실행하면 엉뚱한 파이썬이 잡혀서 오류가 났습니다.

해결 방법은 의외로 간단했습니다. 어떤 파이썬을 쓸지 제가 직접 지정해주는 것.
그래서 저는 프로젝트 규칙 문서에 "반드시 `py -3.11`을 사용한다"라는 한 줄을
못 박아 두었습니다. 그 뒤로는 같은 문제가 재발하지 않았습니다. 별것 아닌 것
같지만, 이게 제가 배운 첫 번째 교훈이었습니다. **AI는 제 컴퓨터 환경을 모릅니다.
제가 알려줘야 압니다.**

## CLAUDE.md — 코드를 모르는 제가 AI에게 규칙을 가르치는 방법

클로드 코드를 실무에 붙이면서 가장 유용했던 개념은 `CLAUDE.md`라는 문서였습니다.
프로젝트 폴더에 이 파일을 하나 만들어두면, 클로드 코드가 작업할 때마다 이 문서를
먼저 읽고 그 규칙을 따릅니다.

저는 여기에 코드 대신 제 업무 지식을 한글로 적었습니다.

| 제가 CLAUDE.md에 적은 것 | 예시 |
|---|---|
| 절대 하면 안 되는 것 | "숫자는 절대 하드코딩하지 않는다" |
| 판단 기준 | "차변 합계 ≠ 대변 합계면 산출물을 만들지 않는다" |
| 애매할 때 규칙 | "매핑이 불분명한 계정은 추측하지 말고 목록에 남긴다" |
| 실행 환경 메모 | "기본 python 말고 반드시 py -3.11 사용" |

코드를 짜는 건 AI 몫이고, 저는 "무엇이 맞고 틀린지"를 정의하는 몫을 맡았습니다.
돌이켜보면 이 역할 분담이 비개발자가 클로드 코드를 실무에 쓰는 핵심이었습니다.
회계 규칙을 아는 사람은 저지, AI가 아니니까요.

## 아직도 헷갈리는 것들

솔직히 말하면 지금도 매끄럽지만은 않습니다. 터미널에 뭔가 긴 에러 메시지가
쭉 뜨면 여전히 심장이 철렁합니다. 대부분은 클로드 코드가 알아서 원인을 설명해
주지만, 가끔은 저도 무슨 말인지 못 알아듣고 그냥 "이거 무슨 뜻이야?"라고
되묻는 수준입니다. "코딩 몰라도 됩니다"가 "아무것도 몰라도 됩니다"는 아니라는
뜻입니다. 터미널을 열고, 명령어 한 줄을 겁내지 않고 타이핑하는 최소한의 용기는
필요합니다.

## 정리하면

- 설치 자체는 명령어 한 줄, 30초면 충분합니다.
- 진짜 넘어야 할 산은 설치가 아니라 "내 업무 규칙을 문서로 명확하게 적는 것"이었습니다.
- CLAUDE.md는 비개발자가 AI와 협업하는 가장 실용적인 방법이었습니다.

지난 글([20년차 재무 실무자가 월마감을 AI에 맡겨본 첫 달 이야기](https://finance-ai-note.blogspot.com/2026/07/20-ai.html))에서
다뤘던 월마감 자동화도, 결국 이 설치와 CLAUDE.md 작성에서 시작된 일이었습니다.
다음 글에서는 차변·대변처럼 기초적이지만 막상 설명하려면 헷갈리는 개념을
재무 실무자 시점에서 풀어보겠습니다.

40대에 AI를 배우기 시작한 재무 실무자의 기록, 계속 이어가겠습니다.
